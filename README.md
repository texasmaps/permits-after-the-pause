# Permits After the Pause

Every Texas Commission on Environmental Quality permit action for a data center project since Gov. Abbott's Sept. 21, 2026 directive to halt them, mapped by county from the agency's own records as compiled by Public Citizen.

Live: https://texasmaps.github.io/permits-after-the-pause/

Companion to [Texas Data Center Watch](https://texasmaps.github.io/) and [Gina on the Road](https://texasmaps.github.io/gina-on-the-road/).

Sources are listed at the bottom of the page.
